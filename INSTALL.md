# Як усталяваць беларускі пераклад Lucky Tower Ultimate

**Вэрсія перакладу:** 1.0 · **Гульня:** Steam, build 25727595 · **Файл:** `LuckyTowerUltimate_Belarusian_v1.0.zip`

## Усталяваньне

1. **Спампуй** архіў `LuckyTowerUltimate_Belarusian_v1.0.zip`.
2. **Адкрый папку гульні.** У Steam адкрый Бібліятэку, націсьні правай кнопкай мышы на Lucky Tower Ultimate і выберы *Кіраваньне → Прагледзець лякальныя файлы*.
   Звычайна гэта `...\steamapps\common\Lucky Tower Ultimate\`.
3. **Распакуй увесь архіў у гэтую папку.** Пасьля распакоўкі файл `winhttp.dll` і папка `BepInEx` мусяць ляжаць побач з `Lucky Tower Ultimate.exe`. Калі Windows спытае пра замену файлаў, адкажы «Так».
4. **Запусьці гульню** праз Steam. Першы запуск можа ісьці на некалькі сэкунд даўжэй.
5. **Уключы мову:** *Settings → Other → Language → «Беларуская»*. Пасьля гэтага ўсё мэню будзе па-беларуску (*Налады → Іншае → Мова*). Выбар захоўваецца.

Правільна распакаваная папка выглядае так:

```
Lucky Tower Ultimate\
  Lucky Tower Ultimate.exe
  Lucky Tower Ultimate_Data\
  BepInEx\              ← новае
  winhttp.dll           ← новае
  doorstop_config.ini   ← новае
  .doorstop_version     ← новае
  changelog.txt         ← новае
  README_BE.txt, README_EN.txt
```

## Калі нешта ня так

- **Мовы «Беларуская» няма ў сьпісе.** Хутчэй за ўсё, архіў распакаваны ва ўкладзеную папку (напрыклад, `Lucky Tower Ultimate\LuckyTowerUltimate_Belarusian_v1.0\...`). Перанясі файлы на ўзровень вышэй, да `.exe`. Калі пасьля запуску ў папцы `BepInEx` зьявіўся файл `LogOutput.log`, значыць BepInEx працуе.
- **Гульня адкрылася ў акне.** Выберы поўнаэкранны рэжым у *Налады → Графіка*.
- **Надпіс «Failed connecting to Steam.» на застаўцы па-ангельску.** Так і мусіць быць: у гэты момант налады мовы яшчэ не загружаныя.
- **Пасьля абнаўленьня гульні частка тэксту па-ангельску.** Гэта новыя радкі, якіх яшчэ няма ў перакладзе. Іх дададзе наступная вэрсія перакладу.
- **Пасьля абнаўленьня гульня не запускаецца.** Выдалі `winhttp.dll`. Гульня запусьціцца бяз перакладу.
- **Ужо стаіць BepInEx 5 для іншых модаў.** Дастаткова скапіяваць толькі папку `BepInEx\plugins\BelarusianLocalization\`.
- **Антывірус лаецца на `winhttp.dll` ці выдаліў яго.** Гэта загрузчык BepInEx, на яго часта ілжыва рэагуюць антывірусы. Дадай папку гульні ў выключэньні і распакуй архіў нанова.
- **Steam Deck / Linux (Proton).** У Steam: правая кнопка на гульні → *Уласьцівасьці → Агульныя → Парамэтры запуску*, устаў `WINEDLLOVERRIDES="winhttp=n,b" %command%`.

## Выдаленьне

Выдалі з папкі гульні `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `changelog.txt`, `README_BE.txt`, `README_EN.txt` і папку `BepInEx`. Калі ў цябе ёсьць іншыя моды на BepInEx, выдалі толькі `BepInEx\plugins\BelarusianLocalization\`.
Захаваньні гульні пры гэтым не чапаюцца. Пасьля выдаленьня выберы ў наладах іншую мову.

Сапраўднасьць архіва можна праверыць па SHA-256:
`8553099d43129cbf23338f2df99c8625298b583a1d2b26e49197ddf574ed3f22`

# Как установить белорусский перевод Lucky Tower Ultimate (RU)

**Версия перевода:** 1.0 · **Игра:** Steam, build 25727595 · **Файл:** `LuckyTowerUltimate_Belarusian_v1.0.zip`

## Установка

1. **Скачайте** архив `LuckyTowerUltimate_Belarusian_v1.0.zip`.
2. **Откройте папку игры.** В Steam откройте Библиотеку, щёлкните правой кнопкой мыши по Lucky Tower Ultimate и выберите *Управление → Просмотреть локальные файлы*.
   Обычно это `...\steamapps\common\Lucky Tower Ultimate\`.
3. **Распакуйте весь архив в эту папку.** После распаковки файл `winhttp.dll` и папка `BepInEx` должны лежать рядом с `Lucky Tower Ultimate.exe`. Если Windows спросит о замене файлов, ответьте «Да».
4. **Запустите игру** через Steam. Первый запуск может занять на несколько секунд больше.
5. **Включите язык:** *Settings → Other → Language → «Беларуская»*. Выбор сохраняется.

## Если что-то не так

- **Языка «Беларуская» нет в списке.** Скорее всего, архив распакован во вложенную папку. Перенесите файлы на уровень выше, к `.exe`. Если после запуска в папке `BepInEx` появился файл `LogOutput.log`, значит BepInEx работает.
- **Игра открылась в окне.** Выберите полноэкранный режим в настройках графики.
- **Надпись «Failed connecting to Steam.» на заставке по-английски.** Так и должно быть: в этот момент настройки языка ещё не загружены.
- **После обновления игры часть текста по-английски.** Это новые строки, которых ещё нет в переводе. Их добавит следующая версия перевода.
- **После обновления игра не запускается.** Удалите `winhttp.dll`. Игра запустится без перевода.
- **Уже стоит BepInEx 5 для других модов.** Достаточно скопировать только папку `BepInEx\plugins\BelarusianLocalization\`.
- **Антивирус ругается на `winhttp.dll` или удалил его.** Это загрузчик BepInEx, на него часто ложно срабатывают антивирусы. Добавьте папку игры в исключения и распакуйте архив заново.
- **Steam Deck / Linux (Proton).** В Steam: правой кнопкой по игре → *Свойства → Общие → Параметры запуска*, впишите `WINEDLLOVERRIDES="winhttp=n,b" %command%`.

## Удаление

Удалите из папки игры `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `changelog.txt`, `README_BE.txt`, `README_EN.txt` и папку `BepInEx`. Если у вас есть другие моды на BepInEx, удалите только `BepInEx\plugins\BelarusianLocalization\`. Сохранения игры при этом не затрагиваются.
